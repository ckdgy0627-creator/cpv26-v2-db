  - 178은 현재 도감/보유 쪽 표시값으로 보이며, 이 프로젝트에서는 분모 **427**만 현재 2026 V2 전체 카드 수 기준값으로 사용한다.
- 용도: 라이브 히트용 **카드 포지션**을 실제 경기 수비 위치와 분리하여 검증.

## 적용 원칙

1. 이 파일은 공식 웹 공지가 아니라 **인게임 직접 관찰 자료**다.
2. 라이브 히트 추천 슬롯은 이 카드 포지션을 사용하고, KBO 당일 실제 수비 포지션은 절대 대체값으로 사용하지 않는다.
3. V2 출시일 이후 10차 Live 신규 카드 목록에 없는 선수는 9차 V2 최초 카드로 간주하되, 과거 날짜 회귀검증에서 별도 충돌이 발견되면 적용 시작일을 수정한다.
4. DB 레코드의 `verification`은 `IN_GAME_SCREENSHOT`으로 표시한다.
